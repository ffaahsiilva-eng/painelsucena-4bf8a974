## Goals
- Complete the GIS Map Editor with robust state management, layer control, and precise tool support (Icons, Sprinklers, Measuring, Polygons).
- Overhaul the Environment Selection UI to match the user-provided "mountain sunset / gold accent" design.
- Ensure 100% responsiveness and high-performance cross-route rendering for all dashboard elements.

## Proposed Changes

### GIS Map Editor (Features/Aspersores)
- **Advanced State Management**: Implement a full Redux-style reducer for map objects, history (undo/redo), and layer visibility.
- **Enhanced Toolbox**:
  - Precise Icon Library (Irrigation, Equipment, Safety).
  - Measurement Tools (Distance/Area calculations in real-time).
  - Drawing Tools (Lines, Polygons, Circles) with grid snapping.
- **Reporting & Export**:
  - GIS data export to GeoJSON and structural JSON.
  - High-resolution PDF generation with dynamic legends and scale indicators.
  - Excel export with embedded map preview.
- **Visuals**: Standardize the "Interactive Map" section within `Aspersores.tsx` with high-contrast UI and smooth performance.

### UI Overhaul (SelecaoAmbiente)
- **Cinematic Background**: Replace the current gradient background with a high-end mountain sunset image.
- **Golden Accents**: Apply Sucena-branded gold lighting and glow effects to environment cards.
- **Modern Cards**:
  - Rebuild cards for "Barcarena" and "Paragominas" using 3D-style icons and golden bar chart assets.
  - Implement smooth hover transitions and prominent "Access" buttons.
- **User Branding**: Display user profile and role with premium typography.

### Technical Detail
- **State Architecture**: `src/features/map-editor/types.ts` and `reducer.ts` will drive all interactivity.
- **Responsiveness**: Use `clamp()` for fluid typography and ensure map tools collapse gracefully on mobile.
- **Performance**: Optimize SVG rendering and canvas rasterization to prevent UI lag during large site edits.
- **Integrations**: Sync map data with existing `site_settings` for persistent project-wide GIS states.

## Approval Required
- Approval to apply the comprehensive dark-golden visual theme across all map-related modules.
